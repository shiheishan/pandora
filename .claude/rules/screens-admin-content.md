# 后台 · 内容与外观

- 公告与知识库的写都是全量覆盖 / 追加新版本：编辑区记住「从哪一版载入」，版本变了而本地没改就换成最新，本地改了就提示「保存会覆盖 / 会在新版本之上再存」并给「载入最新」，不要直接把用户的输入冲掉。
- 公告「已撤回」是终态、只读，只给「复制为新公告」；已发布的公告不能退回草稿、发布时间不能改（后端 409），按钮取舍集中在 `logic.ts`。
- 公告与知识库都是「工具栏 + 表格 + 编辑弹窗」（10-16 设计稿）：公告 `#/content/announce/<id|new>?f=<状态>`，状态筛选带计数；知识库 `#/content/kb/<slug|new>?k=<类型>&q=<搜索>`，类型筛选**不带计数**。保存、撤回、归档成功后关弹窗。
- 知识库发布只归档「同一受众组合」的旧发布版；受众字段默认沿用上一版，改了受众要提示旧版不会被自动归档（`logic.ts` 的 `audienceChanged`，只比语言、平台、限定套餐、可见性）。
- 知识库界面没有摘要、复审日期、客户端版本区间、类型选择与旧版恢复（10-16 删）；接口仍收这几个字段，`kbBody` 从来源版本原样带上，不让保存新版本把旧值清掉、悄悄改了受众。版本历史在弹窗里只读列出。
- 主题没有 `custom_css`（10-14 前后端一起删）：schema、请求、假后端都不带；保存主题响应只有 `saved`。插槽保存的 `dropped`（净化丢掉的内容）照旧。
- 站点名只有一个来源——系统设置 `site.name`（门户标题、浏览器标签、邮件 `{{site}}` 与发件人名、订阅配置名都取它），在本页「站点设置」段（`ThemeTab.tsx` 的 `SiteCard`，与站点时区一起，`v1/settings/site`）里改。同一张卡下半段是 SEO 三项（搜索关键词 ≤200 字、站点描述 ≤160 字、允许搜索引擎收录门户首页开关，缺省关），与站点名、时区共用一个「保存」，只提交改了的键；文案与后端校验同字。主题编辑器没有站点名；激活确认框写明站点名不随主题变化。
- 站点设置的形状与查询只在 `src/admin/site.ts` 定义一次（`siteSettingsSchema`、`useSiteSettings`，缓存键 `['admin','content','site']`），本目录的 `schemas.ts` / `queries.ts` 只再导出；后台外框的标题与侧栏读同一份缓存，这里保存后 `invalidate('site')` 外框跟着变。
- 主题（10-16）：列表逐行，「复制」= 读出来源主题预填新建弹窗再 create（code `<来源>-copy`、名称「<来源> 副本」）；内置主题只能复制、激活。编辑弹窗只有标识（新建时）、名称、标语、浅色组 5 色（`theme.ts` 的 `THEME_COLORS`：背景 `--bg`、分隔线 `--border`、次要文字 `--text-2`、主文字 `--text`、品牌色 `--brand`，必须 #RRGGBB）；没有深色组、Logo 上传、实时预览。保存仍整组提交两组 48 个令牌：没在界面上的从来源主题原样带上（空白新建用设计规范默认值），来源已有的 data: Logo 也原样带上。品牌色和来源不同时，浅色组的 `--brand-deep`（压暗 30%）、`--brand-mark`（提亮提纯）、`--brand-line`（混向背景 70%）由 `brandDerived` 按新品牌色推出来（门户主按钮、hot 按钮渐变与主卡描边用它们），品牌色没变就保留来源的值。
- 主题保存 422 的 `fields` 键（`code`、`name`、`branding.<键>`、`tokens.<组>.<变量名>`）与 `theme.ts` 的前端校验同名，改一边要改另一边。
- 插槽失焦时内容真的变了才保存（每次保存都 reauth + 新幂等键），保存后回填净化后的内容并逐条提示被过滤的片段。
- 公告可见范围只有「套餐 + 用户组」，不提供「即将到期」。
- av4（样稿 admin-v4）：「新建公告」「新建文章」在页头 `PageActions`（主按钮带加号）；两张表 `Table boxed`（次要列照样稿 `hideOnMobile`），已撤回的公告、已归档的文章整行淡显（`rowClassName`）；置顶是灰标签。主题与插槽页四张 `Card`（站点设置 / 首页 / 主题 / 前端插槽），区块标题与说明在卡片头（`subtitle`），主题卡的「新建」是次要按钮带加号；主题行用 `RowList`，插槽两列（名称、key 与开关 | 文本框）。后台不写 `--brand*`。
- 首页卡（`HomeCard.tsx`，10-20）：开关（缺省开，关了用户端根地址直接是登录页）、介绍（纯文本、换行分段、≤500 字）、常见问题（≤20 条，问题 ≤100 字不许换行，回答 ≤500 字，可上移 / 下移 / 删除），`GET/POST v1/settings/home`，缓存键 `['admin','content','home']`；草稿 null = 没动过，只提交改了的键（faq 整组），前端校验与后端同字同键（`homeForm.ts`：`intro`、`faq`、`faq.<i>.q`、`faq.<i>.a`），保存走 reauth。套餐与价格取自套餐页，不在这里改。
