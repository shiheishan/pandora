# Grok 的开工指令

`scripts/cursor-launch.sh` 按下面三段之一填占位，作为 `cursor-agent -p` 的指令，不要手抄。改措辞时几段一起看；占位名改了要同步脚本（脚本发现没替换干净的占位会拒绝启动）。

## 任务 worktree

```text
你在 <worktree> 这个 git worktree 里工作，分支 <分支>。先读根目录的 CLAUDE.md，再读 <开工文件>，严格照做：只改其中「归属」（或「本轮放开的归属」）列出的文件，不碰这个目录以外的任何文件（主目录 <主目录> 只可读开工文件点名的证据和 ops-local/memoh-ci 下的两个等待脚本）。不登录、不 ssh 任何服务器，除非开工文件里有「服务器只读红线」一节，那时只按那一节做。先写修前会红的测试，再改代码。本地跑完开工文件要求的命令：go 命令一律加 GOTOOLCHAIN=<go 版本>，npm ci 不和 go 命令同时跑。按项提交；提交前的 gitleaks 钩子命中就停下，写进报告。只推送 <分支>，不 force push；推送报签名失败就停下写进报告，不改走 HTTPS。推送后跑 <主目录>/ops-local/memoh-ci/wait-status.sh <sha> 和 BRANCH=<分支> <主目录>/ops-local/memoh-ci/wait-github.sh <sha> 等到结论，红了先按 .claude/skills/ci-triage/SKILL.md 查清原因并修。最后把报告按开工文件「报告」（或「交回」）一节的格式写进 <报告文件>，这个文件不提交；最终回复只写一段简述和报告路径。开工文件没写清、或需要改归属以外的文件时，不要自己扩大范围，把问题写进报告后结束。
```

## 只读巡检

```text
读 <开工文件>，严格照做。这是服务器只读巡检，其中「服务器只读红线」一节一条都不能碰：只登录点名的机器，只跑允许的查看类命令，不读不抄任何秘密，写进文件的 IP 和域名换成占位符，本机只写 <worktree> 这个目录。做完把报告写进 <报告文件>，最终回复只写一段简述和报告路径。
```

## 子 agent 转手

```text
你在 <worktree> 这个 git worktree 里工作，分支 <分支>。这是一个 opus 子 agent 转给你的机械部分：先读根目录的 CLAUDE.md，再读 <开工文件>，严格照做，只改其中列出的文件，不碰这个目录以外的任何文件（主目录 <主目录> 只可读开工文件点名的证据）。不登录、不 ssh 任何服务器。本地跑完开工文件要求的命令：go 命令一律加 GOTOOLCHAIN=<go 版本>，npm ci 不和 go 命令同时跑。按项提交；提交前的 gitleaks 钩子命中就停下，写进报告。不推送、不等 CI，推送与 CI 由转手给你的子 agent 负责。最后把报告按开工文件「报告」一节的格式写进 <报告文件>（不提交）：每项做了什么、改了哪些文件、提交 sha、跑的命令与关键输出、没做的和原因；最终回复只写一段简述和报告路径。开工文件没写清、或需要改列出以外的文件时，不要自己扩大范围，把问题写进报告后结束。
```
