# 内置升级发版公钥目录

本目录用于存放 pdnd 在线升级所信任的 ed25519 发版公钥文件，通过 `go:embed` 编译进 pdnd 二进制。

## 文件格式与规则

- 每个公钥文件以 `.pub` 结尾（例如 `release-2026.pub`），只包含单行文本。
- 内容为标准 base64 编码（`base64.StdEncoding`）的 32 字节 ed25519 公钥明文。
- 公钥对应的 `key_id` 为：`hex(sha256(公钥 32 字节))[:16]`（16 位小写十六进制字符串）。
- 目录内支持同时存放多把 `.pub` 公钥，用于无缝轮换（先发一个同时内置新旧两把公钥的版本，随后再启用新私钥签名）。
- **没有任何 `.pub` 文件时，Keyring 为空，一切升级都会以 `signature_invalid` 拒绝。**

## 密钥生成流程

在 `pdnd` 目录下执行签名工具生成密钥对：

```bash
go run ./release/signmanifest -gen <前缀>
```

- 该命令会在本地生成私钥 `<前缀>.key`（权限 0600）与公钥 `<前缀>.pub`。
- **安全红线**：本仓库公开，**私钥绝不提交进仓库**，只能存入维护者的密码管理器与 GitHub release CI 的 environment secret 中。
- 只有生成的 `<前缀>.pub` 公钥文件提交并放入本目录。
