# panel/
> L2 | 父级: /CLAUDE.md

面板主体：一个 Go module（github.com/aegispanel/aegis），产出三个 HTTP 域网关、一个节点代理和一组运维命令，共用 internal/ 下的业务域与平台层。安全与财务不变量下沉到 PostgreSQL（RLS、追加写触发器、DEFERRABLE 配平、回调唯一约束），网关只是策略的执行者，不是策略的来源。
