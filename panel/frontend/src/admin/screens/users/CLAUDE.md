用户（管理后台-03-用户.dc.html）。「用户列表」标签是列表 + 560 宽详情抽屉，状态全在地址上：#/users/list/<用户 id>/<抽屉标签>?f=<状态>&g=<用户组>&q=<搜索>&o=<偏移>，刷新、分享、从仪表盘排行或工单「查看用户」点进来都落在同一处。用户组、批量运营、设备策略、流量重置四个标签在第 ④ 步接入，目前是占位页。
保留规则 2 贯穿整个模块：后台看不到订阅地址。列表、详情、画像都不含令牌；订阅标签用一句说明代替设计稿的「订阅地址 + 复制」；换发订阅链接只选订阅、填原因，响应 schema 用 strict 守住「不回令牌」（5.A D-B-1 / R11），成功后提示让用户到门户重新复制。搜索框按订阅令牌反查只比哈希，同样不暴露地址。
权限分层：iam.user.read 看列表与抽屉；iam.user.write 才有启停封禁、设新密码、换发、分组与设备上限；billing.provider.write 才能调账；security.audit.read 才出现「风控」标签与画像里的注册 IP（明文 IP 只在那条接口里）。写操作取 src/admin/actions.ts 的三件，reauth 由外框对话框接管。
待决按「未决前」：D-B-2 重置密码按方案 A（管理员直接设新密码 + 原因，不发邮件）；D-B-8 设备标签按方案 A（只有在线台数与上限，不列逐台客户端与 IP）。
